# BAT Scripts

Колекція моїх .bat скриптів для Windows.

## Скрипти

### del-mov-mp4.bat
Видаляє відеофайли (.mov, .mp4, .mxf) старші за 10 днів у папці `Y:\TEST`.

**Як користуватись:**
1. Відкрий файл у блокноті.
2. Зміни `set "sourceFolder=Y:\TEST"` на свою папку.
3. Запусти подвійним кліком.

**Увага:** файли видаляються назавжди, без кошика!
